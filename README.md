>  **ShowTime** is a full-stack movie ticket booking application built with the **MERN stack (MongoDB, Express.js, React.js, and Node.js)**. It enables users to browse movies, view show timings, select seats, and book tickets through a responsive and user-friendly interface. The application uses **Clerk Authentication** for secure user management and **Clerk Webhooks** to synchronize user data with the database, providing a seamless and secure booking experience. 🚀🎬
